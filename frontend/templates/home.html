KNOWLEDGE BASE

FREQUENTLY ASKED QUESTIONS

DO I NEED DOCKER INSTALLED LOCALLY TO RUN THESE LABS?
No local software or hypervisor installations are required for students! The platform includes a native web-based IDE, interactive CLI emulator, and background task engine that executes instructions directly within an isolated sandbox environment.
HOW DOES THE REAL-TIME SUBPROCESS ENGINE WORK?
When a command is triggered in a lab worksheet (e.g. docker build or docker run), the Flask backend spawns a dedicated subprocess worker thread, collects real-time stdout/stderr, streams the logs back to your interface, and verifies process exit codes.
HOW DO FACULTY MEMBERS MANAGE STUDENT ROSTERS?
Faculty can upload standard .xlsx roster spreadsheets directly via the Faculty Console. The system automatically creates unique Student IDs (e.g. STU001) and generates secure default passwords for the entire class roster.
HOW DO STUDENTS SUBMIT LAB COMPLETIONS FOR GRADING?
Each lab includes a "Submit & Verify" action button. The automated test engine audits all step checkmarks, container inspection results, and port connectivity before committing the verified completion timestamp to the student's persistent database record.
CAN FACULTY ATTACH TUTORIAL VIDEOS TO SPECIFIC LABS?
Yes! The Faculty Dashboard features a Lecture Video Manager allowing instructors to link YouTube or MP4 tutorial URLs for Lab 1, Lab 2, Lab 3, and Lab 4. Students can watch these directly inside their lab worksheets via the "Video Tutorial" modal.
