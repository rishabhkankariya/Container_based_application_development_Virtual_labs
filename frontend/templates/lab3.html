LAB 3 INSTRUCTIONS

Complete these tasks in the VS Code Web IDE to build and run your custom web app container:
1. CREATE INDEX.HTML Required
CLICK + IN EXPLORER SIDEBAR AND WRITE HTML CODE FROM REFERENCE BELOW:

</html>
2. CREATE DOCKERFILE Required
CLICK + TO CREATE DOCKERFILE WITH NGINX INSTRUCTIONS:
REFERENCE (HOVER FOR EXPLANATION)
FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
3. PULL HELLO-WORLD IMAGE Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker pull hello-world
4. RUN HELLO-WORLD CONTAINER Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker run hello-world
5. BUILD WEBSITE IMAGE Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker build -t my-website .
6. RUN WEBSITE CONTAINER Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker run -d -p 8080:80 my-website
7. STOP & START CONTAINER Required
RUN COMMANDS IN TERMINAL CONSOLE BELOW:
docker stop <container_id>
docker start <container_id>
8. CLEAN SYSTEM PRUNE Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker system prune
9. INSPECT ALL CONTAINERS Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker ps -a
10. FORCE REMOVE CONTAINER Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker rm -f <container_id>
