LAB 5 INSTRUCTIONS

Build a multi-container network architecture connecting a Flask Sum Microservice and a Client Application container over custom Docker network app-net:
1. CREATE SUM MICROSERVICE (app.py) Required
CREATE app.py IN EXPLORER AND WRITE FLASK API:
REFERENCE
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/add', methods=['GET'])
def add():
  a = float(request.args.get('a', 0))
  b = float(request.args.get('b', 0))
  return jsonify({"number1": a, "number2": b, "sum": a + b, "container": "sum-microservice"})

if __name__ == '__main__':
  app.run(host='0.0.0.0', port=5000)
2. CREATE CLIENT APP (client.py) Required
CREATE client.py TO CALL MICROSERVICE OVER DOCKER NETWORK (sum-microservice:5000):
REFERENCE
from flask import Flask, request, jsonify
import requests

app = Flask(__name__)
MICROSERVICE_URL = "http://sum-microservice:5000/add"

@app.route('/calc', methods=['GET'])
def calc():
  a = request.args.get('a', 10)
  b = request.args.get('b', 20)
  res = requests.get(f"{MICROSERVICE_URL}?a={a}&b={b}")
  return jsonify({"client_status": "success", "network_result": res.json()})

if __name__ == '__main__':
  app.run(host='0.0.0.0', port=8080)
3. CREATE DOCKERFILES Required
CREATE Dockerfile.microservice AND Dockerfile.client:
Dockerfile.microservice REFERENCE
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]
4. CREATE DOCKER NETWORK Required
RUN COMMAND IN TERMINAL BELOW:
docker network create app-net
5. BUILD & RUN MICROSERVICE ON NETWORK Required
RUN COMMANDS IN TERMINAL:
docker build -f Dockerfile.microservice -t sum-microservice .
docker run -d --name sum-microservice --network app-net -p 5000:5000 sum-microservice
6. BUILD & RUN CLIENT ON NETWORK Required
RUN COMMANDS IN TERMINAL:
docker build -f Dockerfile.client -t sum-client .
docker run -d --name sum-client --network app-net -p 8080:8080 sum-client
