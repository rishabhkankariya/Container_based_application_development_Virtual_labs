LAB 6 INSTRUCTIONS

Scale microservice container instances up and down dynamically using Docker Compose to manage load:
1. WRITE MICROSERVICE (app.py) Required
CREATE app.py FEATURING HOSTNAME IDENTIFIER TO TRACK REPLICAS:
REFERENCE
import socket
from flask import Flask, request, jsonify

app = Flask(__name__)
HOST_ID = socket.gethostname()

@app.route('/add', methods=['GET'])
def add():
  a = float(request.args.get('a', 0))
  b = float(request.args.get('b', 0))
  return jsonify({"number1": a, "number2": b, "sum": a + b, "handled_by_replica": HOST_ID})

if __name__ == '__main__':
  app.run(host='0.0.0.0', port=5000)
2. CREATE DOCKERFILE Required
CREATE Dockerfile IN VS CODE EXPLORER:
REFERENCE
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY app.py .
EXPOSE 5000
CMD ["python", "app.py"]
3. CONFIGURE DOCKER-COMPOSE.YML Required
CREATE docker-compose.yml DEFINING SCALABLE STACK:
REFERENCE
version: '3.8'
services:
  sum-microservice:
    build: .
    ports:
      - "5000:5000"
    deploy:
      replicas: 1
4. DEPLOY BASELINE STACK Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker compose up -d
5. SCALE MICROSERVICE REPLICAS UP Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker compose up -d --scale sum-microservice=3
6. SCALE MICROSERVICE REPLICAS DOWN Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker compose up -d --scale sum-microservice=1
