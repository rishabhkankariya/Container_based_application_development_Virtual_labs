LAB 4 INSTRUCTIONS

Complete these tasks in the VS Code Web IDE to package and deploy your Flask Sum Microservice container:
1. CREATE APP.PY Required
CLICK + IN EXPLORER SIDEBAR AND WRITE FLASK CODE FROM REFERENCE BELOW:
REFERENCE (TYPE MANUALLY - COPY BLOCKED)
from flask import Flask, request, jsonify
app = Flask(__name__)
@app.route('/sum')
def get_sum():
  a = float(request.args.get('a', 0))
  b = float(request.args.get('b', 0))
  return jsonify({'sum': a + b})
if __name__ == '__main__':
  app.run(host='0.0.0.0', port=80)
2. CREATE DOCKERFILE Required
CLICK + TO CREATE DOCKERFILE WITH PYTHON MICROSERVICE INSTRUCTIONS:
REFERENCE (TYPE MANUALLY - COPY BLOCKED)
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY app.py .
EXPOSE 80
CMD ["python", "app.py"]
3. CREATE REQUIREMENTS.TXT Required
CLICK + IN EXPLORER SIDEBAR AND WRITE DEPENDENCIES FROM REFERENCE BELOW:
REFERENCE (TYPE MANUALLY - COPY BLOCKED)
flask==3.0.0
gunicorn==21.2.0
4. BUILD MICROSERVICE IMAGE Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker build -t sum-microservice .
5. RUN MICROSERVICE CONTAINER Required
RUN COMMAND IN TERMINAL CONSOLE BELOW:
docker run -d -p 8080:80 sum-microservice
